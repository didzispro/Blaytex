# Blaytex



## 🎮 About the Game
Blaytex is a fighting game where you battle enemies in rounds until you win.  
It mixes survival and strategy elements with different game modes.


![Gameplay Screenshot](Screenshot1.png)

---

## ⚔️ What the Game Includes

### 🧠 Core Gameplay
- Survival gameplay
- Strategy-based fighting
- Round-based battles

![Gameplay2 Screenshot](Screenshot2.png)

---

### 💰 Betting System
- Bet on which enemy will win (50/50 luck system)
- Adds risk and prediction gameplay

---

### 🎨 Customization
- Name your character (Local Multiplayer & Betting modes)
- Not available in Story Mode

---

### 👥 Local Multiplayer
- Play with friends on the same screen
- Fast-paced versus battles

---

## 📖 Story Mode
The game includes a story mode with an ending you will discover yourself.
